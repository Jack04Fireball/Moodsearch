Moodsearch GitHub Pages

1. Create a new GitHub repository.
2. Upload index.html and privacy.html to the repository root.
3. Go to Settings > Pages.
4. Under Source, select Deploy from a branch.
5. Choose the main branch and /root folder.
6. Save.
7. Wait a minute. Your site will appear at:
   https://YOUR-USERNAME.github.io/REPO-NAME/

Use in Pinterest form:
- Website/App link: your GitHub Pages root URL
- Privacy policy link: your GitHub Pages root URL + privacy.html

Suggested app purpose text:
Moodsearch allows users to connect their own Pinterest boards and use selected Pins as visual inspiration for search and creative discovery within the app. Pinterest data is used only in the context of the authorized user and is not sold or used for third-party advertising.
