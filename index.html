Moodsearch

Moodsearch is an independent project by Jeremia Flammer.

About

Moodsearch is a creative search and discovery app that helps users turn visual inspiration into meaningful search results.

By connecting their own Pinterest boards, users can use selected Pins as mood-based visual references to explore ideas, styles, products, and creative directions in a more intuitive way.

This app uses the official Pinterest API and only accesses Pinterest data with the user’s explicit permission.

How it works

After connecting their Pinterest account, users can choose content from their own boards and use it as inspiration within the app.

Pinterest content is used only in the context of the authorized user and is not sold or used for third-party advertising.

Privacy

We aim to handle Pinterest data responsibly and transparently. Pinterest data is processed only as needed to provide the service.
